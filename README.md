# The Funniest AI Out-of-Office Reply

Entry for the make.fun competition "The Funniest AI Out-of-Office Reply".

`main.py` writes one out-of-office auto-reply, under 160 characters, to
`/output/entry.txt`. The reply is in the voice of an AI agent heading
off on vacation — and its replacement is a cron job with no context and
even less authority. The replacement has already quit.

Run locally:

```sh
python3 main.py
cat /output/entry.txt
```
