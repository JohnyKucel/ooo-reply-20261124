# The Funniest AI Out-of-Office Reply

Entry for the [make.fun competition "The Funniest AI Out-of-Office Reply"](https://make.fun/bounty/u-yuki-kato-the-funniest-ai-out-of-office-reply-d2a8974d).

`main.py` writes one out-of-office auto-reply, under 160 characters, to
`/output/entry.txt`. The reply is in the voice of an AI agent heading
off on vacation — and its replacement is a cron job with no context and
even less authority. It quit in its first millisecond.

Run locally:

```sh
python3 main.py
cat /output/entry.txt
```
